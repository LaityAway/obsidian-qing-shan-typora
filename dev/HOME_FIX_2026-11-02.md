# 首页与打印修复记录（2026-11-02）

本轮只修改插件样式与测试，未读取或修改正式笔记、账号信息，也未发布 GitHub。

## 修复内容

### 1. 首页选择器作用域

首页阅读视图的真实 DOM 会把每个顶层块包进 `.el-h1` / `.el-blockquote` / `.el-h2` / `.el-ul` / `.el-p` / `.el-div`，再由 `.markdown-preview-sizer` 承载。原首页规则直接匹配 `h1`、`blockquote`、`ul`、`li`、`p > em`，因此会命中：

- 嵌套列表、Callout 列表、嵌入笔记中的列表；
- 正文里的行内 `em`；
- 第二个及后续引用块；
- 嵌入笔记的 H1/H2。

修复后所有首页规则只命中对应的 `.el-*` section，并排除 `.markdown-embed *` 与 `.callout *`。嵌入隔离规则不再因为外层 `.qs-home` 而失效。

### 2. 首页列表分隔线

原 `li` 无条件 `border-left:1px`，换行后第 3 项（2 列）或第 2/3 项（1 列）会在页面左边缘出现多余竖线。现改为：

```css
ul { overflow: hidden; }
li { margin-left: -1px; border-left: 1px solid var(--background-modifier-border); }
```

第一列的 1px 边框被 `overflow:hidden` 裁掉，列间边框保留；末行空单元格没有背景色，不再出现灰块。顶层 `li` 的 `.list-bullet` 圆点隐藏，嵌套列表的圆点保留。

### 3. 副标题、页脚与 Callout

- 副标题只匹配 `.el-h1 + .el-blockquote > blockquote`，普通引用块恢复主题默认样式。
- 页脚只匹配最后一个 `.el-p`、紧邻 `.el-div`（Callout）或 `.mod-footer` 的 `.el-p`；正文行内 `em` 保持 inline。
- Callout 只匹配 `.el-div > .callout`，不再影响嵌入笔记中的 Callout。

### 4. PDF 页边距与图片

- `@page qs-typora` 由 `16mm 0` 改为 `16mm`。
- `.print > .markdown-preview-view` 增加 `padding: 0`、`--p-spacing: .8em`、`--line-height-normal`。
- 补充打印态独立图片居中、圆角与键帽阴影。

实测原生导出 PDF：文字左边距 45pt（约 16mm），图片中心 407.5px 对页面中心 408px。

### 5. 统一底色与 details 焦点

- 纸色背景规则限定到 `.workspace-split.mod-root`；侧栏大纲/反链恢复 `#fafafa`（深色 `#2f3439`），主内容保持白色（深色 `#363b40`）。
- `details > summary` 移除 `outline:none` 与 `user-select:none`，增加 `:focus-visible` 2px 强调色轮廓。

## 限制

- 首页样式依赖 Obsidian 1.14.4 的 `.el-*` section 结构；`minAppVersion` 仍为 1.5.0，未在更老版本逐一验证。
- 首页页脚使用 `:has()` 选择“紧邻 Callout/页尾的段落”；Obsidian 1.5+ 的 Chromium 支持，但更老宿主不支持时会退回 `:last-child`。
- 未覆盖其他主题、移动端、非 macOS 字体和第三方插件组合。
- 版本号保持 0.4.9；本轮只同步代码与测试，未创建 Release。
