# Qing Shan Typography 修复与验收结果

本轮已确认的问题完成本地修复，并在隔离 Obsidian 1.14.5 中通过验收。案卷的 20 项已逐项处置；这不表示 20 项全部是真实缺陷或全部需要修改。没有发布、推送 GitHub，也没有读取或修改正式笔记与账号信息。

## 修复内容

- 恢复 Obsidian 对实时预览行号的控制。当前宿主的 gutter 位于 sizer 内，移除强制隐藏即可保留行号和原有居中；没有照案卷重写编辑器结构。
- 为 body 下的双链悬浮预览补齐正文、标题和代码排版；保留浮窗尺寸与位置，覆盖浅色、深色及深色 diff 删除行配色。
- 为原生 PDF 打印容器补齐语法高亮、键帽、折叠块和 Mermaid 约束，并通过实际原生导出验证。
- 保留并验收此前的 Popout 关闭兜底、滑块保存合并、标题行高统一和嵌套公式防御规则。
- 重建运行时回归：精确检查虚构库路径、校验受测插件哈希，使用统一端口；严格模式下环境缺失直接失败，不静默跳过。

## 验证结果

执行命令：

```sh
QS_REQUIRE_RUNTIME=1 node --test dev/*.test.cjs
```

结果：79 项通过，0 失败，0 跳过。Node 的计数包含父测试项；其中 17 个子场景在真实隔离 Obsidian 中运行：

1. 行号开关、600/1440/1900px 视窗以及 Typora/固定/全宽模式下的 gutter 与正文几何。
2. 阅读与实时预览的固定宽度和全宽。
3. 真正的 Source Mode 编辑与原生行号。
4. 无强制点击的标题折叠与展开。
5. 窄窗和宽窗的 1000 字符代码、长 URL 末尾光标可见性。
6. 宽表横向滚动。
7. 列拖拽及对应单元格数据完整性。
8. 滑块即时更新、保存合并、禁用与重新启用。
9. 行拖拽及单元格数据完整性。
10. H1–H6 行内标题与行容器的计算行高一致性。
11. 浅色与深色悬浮预览排版和尺寸。
12. 阅读与实时预览搜索的活动匹配项切换。
13. 首行缩进开启时输入标题与列表的文本完整性。
14. 真实 Popout 自动继承样式、关闭后释放文档引用；测试没有手动调用 applySettings 来补救状态。
15. 原生 PDF 导出代码、键帽、details、数学与实际渲染的 Mermaid。
16. 标题开关、真实设置面板控件、宽度持久化及窄窗 padding。
17. 卸载清理与重新加载。

另外运行了设置规范化、失败重试、并发写入、卸载/重载、字体、主题、对比度、嵌入内容和版式等单元/合成浏览器回归。独立代码审查发现的深色浮窗配色遗漏和两处测试证据不足均已修正并复核通过。

原生 PDF 已转成 PNG 逐页检查，样张为 1 页：键帽、折叠块、代码、图表与公式均可见，没有发现裁切、重叠或乱码。PDF 字符颜色检查确认关键字和字符串不是单色正文继承。

## 可复现流程与证据

在插件目录运行准备脚本，只复制插件代码到固定临时库，不复制用户笔记或设置：

```sh
node dev/prepare-runtime.cjs
```

在单独终端启动隔离应用，保留进程直到测试结束：

```sh
/Applications/Obsidian.app/Contents/MacOS/Obsidian --user-data-dir=/tmp/qs-audit-20261101/profile --remote-debugging-port=19352
```

再运行严格验收命令。原生 PDF 测试需要 `pdftotext`；测试会将本地弹出的保存路径固定在临时库目录外的测试输出位置，并恢复对话框方法。

证据位于 `dev/acceptance-final-20261101/`：完整测试日志、当前源文件 SHA-256、原生 PDF、渲染 PNG 和 PDF 文本/颜色检查。该目录日期沿用本轮测试批次，最终报告日期为 2026-11-02。

验收范围为当前 macOS、Obsidian 1.14.5、受测插件代码和记录的虚构场景。它不是对任意主题、第三方插件、宿主历史版本、移动端或进程强退写盘的无限保证。未改支持平台声明、未改版本号、未发布 GitHub。
